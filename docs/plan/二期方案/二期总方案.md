# 二期扩展方案

更新日期：2026-10-20。状态：仅规划，未授权安装、迁移、采购或上线。
一期边界见[一期总方案](../一期测试方案/一期总方案.md)。

## 范围与原则

一期完成中英文官网、Java/MySQL、/admin管理、服务器磁盘媒体、询盘和人工客服。
Redis与OSS不作为一期启动条件，二期按真实容量、访问表现和业务需求逐项批准。
不把后续规划描述为已实现，不因拥有OSS资源就自动开通调用或迁移。
H2转MySQL属于一期正式部署准备，不推迟到二期。

## 二期A步：Redis与多实例能力

- 评估缓存、共享会话及原子限流，重新启用Redis依赖与环境配置。
- 当前本机会话重启失效，限流和缓存不跨实例；增加实例前先完成共享状态设计。
- 区分缓存与会话容量、TTL及淘汰策略，验证缓存失效、事务边界和Redis不可用处理。
- 核实受信代理IP，不相信任意转发头；不要将Redis本身当作防机器人完整方案。
- Redis仅内部监听，凭证注入，配置持久化、告警及2GB容量测试；不足时先确认升级。
- 验收共享登录/退出、并发限流、发布缓存一致性和重启恢复。

## 二期B步：OSS与媒体迁移

- 核实Bucket地域、Endpoint、存量文件、RAM权限、流量价格及越南访问。
- 在本地存储实现之外增加存储适配，不将云厂商密钥暴露给浏览器。
- 公开/私有资源隔离；私有下载使用授权与短期签名，不开放公共写权限。
- 若选直传，限制STS/签名有效期、对象范围、CORS，服务端确认上传结果。
- 保留稳定媒体ID，设计对象映射、校验和、逐批迁移及回退；源文件确认迁移成功后再按审批清理。
- 图片/PDF/预处理MP4不默认接转码、点播或传输加速。
- CDN按跨运营商实测和费用评估选择，不默认购买。
- 验收旧链接兼容、草稿不可公开、权限、备份、费用告警及越南媒体加载。

## 二期C步：管理能力与多语言

- 多管理员、角色权限、密码修改、完整操作审计。
- 询盘授权联系方式查看、跟进备注、通知及流程增强。
- 专用产品规格、资料版本、媒体删除/撤销发布和引用检查。
- 先确认数据模型，再设计翻译子表，使用(content_id, locale)唯一约束。
- 预留越南语等语言，不继续追加name_vi/name_fr固定列。
- 通过V2、V3等新迁移实施，更新SQL字段表、Entity、Mapper、DTO/VO和接口文档。

## 二期D步：AI与访问优化评估

- DeepSeek及知识库仅在再次批准后评估；不提前安装Dify、向量库或模型服务。
- 确认预算、资料授权、隐私、知识同步、拒答与人工转接后再实施。
- 未批准前，前端不显示AI入口、占位或隐藏加载SDK。
- 新加坡地域迁移及CDN按越南实测结果选择，2GB机器不默认承载AI平台。
- 保留当前人工客服渠道，不将模型回复冒充人工服务。

## 实施门槛

- 一期官网、后台、询盘与媒体真实联调验收通过。
- 每项扩展先确认需求、风险、费用与服务器资源，再实施。
- 修改前备份，保留回退路径，不覆盖现有业务或历史Flyway迁移。
- 实际运行测试后才能标记通过；测试、生产配置和秘密信息隔离。
