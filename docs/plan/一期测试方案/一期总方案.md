# 阿里云一期分步测试方案

更新日期：2026-10-20。状态：官网、/admin原型及Java基础接口已实现；前后端联调、服务器部署与越南验收未完成。

## 1. 最新范围与文档优先级

当前按“先看到网站，再逐步接入真实业务”推进。每一步单独验收，不要求第一步一次完成全部一期功能。

本目录明确各步交付范围；根目录原有需求和技术文档继续作为完整目标参考。若发生范围冲突，以本目录的最新分步安排为准。

- 复用已有阿里云 2 核 2GB 服务器，一期A步不新购、不扩容。
- A步先展示网站；一期整体包含管理员登录、内容管理、数据库和本地媒体上传。
- 默认中文，顶部可切换英文，环境变量 `SITE_DEFAULT_LOCALE=zh` 可调整默认语言。
- Nuxt 4 + Vue 3官网，同一工程的`/admin`使用Element Plus；Java 17 + Spring Boot + MyBatis提供业务接口。
- 正式数据库使用MySQL；H2仅供本地调试，不能将H2验证视为MySQL生产验收。
- 一期不接OSS、不启动Redis，采用Servlet Session、本机内存缓存和限流，单Java实例运行。
- 一期不部署AI，前端不显示AI入口、占位或隐藏加载；二期仅评估，不默认上线。
- 人工客服仅一个入口，渠道未配置时提供联系页面，不伪装成已接通的聊天。
- 越南访问方案继续保留，当前先使用已有资源，不默认其在新加坡。

## 3. 一期A步技术及数据决策

一期A步保留 Nuxt SSR，服务器仅运行 Nginx 和单实例 Nuxt，不启动 Java/MySQL/Redis；后续无需从另一套前端重写。

展示内容放在独立 TypeScript/JSON 数据文件，经统一内容访问接口读取，不散落到页面模板。一期B步用 API 实现替换本地实现，保持产品 ID、语言、分类、品牌和 URL 结构。

数据库可以没有业务记录，甚至未安装；一期A步不存在建表、初始化数据或数据库连接要求。示例内容不伪装为从数据库获取。

图片使用用户提供的`.images/lb`、`show`、`brands`素材，复制到`website/public/images`；不另行生成图片，不接OSS。C步新增上传资源存入服务器独立目录。

一期A步不为完成布局虚构视频、证书、代理授权或材料性能声明。缺少实际视频/PDF 时不展示假的播放/下载按钮；相关组件接口留待后续。

## 4. 后续扩展原则

- 登录仅后续后台管理员需要，官网浏览不要求登录；不预先展示登录按钮或无用后台入口。
- 资源对象保存object key和元数据，不保存服务器绝对目录。`MEDIA_PUBLIC_ROOT`与`MEDIA_PRIVATE_ROOT`分离，Nginx仅映射公开目录；禁止写入`.output`、target或JAR部署目录。
- 当前中英文使用name/name_en等固定字段；二期新增语言时设计翻译子表，不声称当前已支持任意语言。
- AI 预留只体现组件边界、内容模型和文档，不创建 AI 空壳服务、数据表或前端面板。
- 使用Knife4j/OpenAPI，公开/共用接口放`docs/api/md/`及`docs/api/json/`，管理/认证接口放`docs/admin/md/`及`docs/admin/json/`，`docs/JAVA_API_INDEX.md`保留索引。
- SQL新增功能使用V2、V3增量迁移，不修改已执行V1；同步更新`backend/sql/README.md`字段表、DTO/VO及测试。
- OSS、Redis、CDN、AI及增强权限统一参考[二期总方案](../二期方案/二期总方案.md)，不作为一期启动条件。

## 5. 资源与费用

一期A步没有新的计算资源采购，服务器续费另记；没有 OSS 上传和媒体流量调用、AI/数据库托管/转码费用。仍可能产生现有服务器流量超额、域名及备份等费用。

本地构建，服务器仅运行。保留已有业务，不覆盖 Nginx 配置和文件；部署前核实端口、剩余内存、地域、备案及域名。

一期B步、C步逐渐引入数据库和后端后重新测 2GB 容量；不足时提出调优/升级建议，不通过删除现有业务腾资源。
