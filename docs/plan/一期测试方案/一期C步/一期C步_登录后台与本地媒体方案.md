# 一期C步：管理员登录、/admin后台与服务器本地媒体

更新日期：2026-10-20。/admin原型及Java基础接口已实现，真实登录、数据持久化及媒体交互联调待完成。部署操作仍需另行授权。

## 1. 目标与范围

- 同一Nuxt工程的`/admin`使用Vue + Element Plus，ERP风格左侧菜单、顶部导航、表格和表单；不是采购、库存或财务ERP。
- 单管理员登录、退出、会话查询与Java服务端授权；多角色和在线密码修改放入二期。
- 仅后台需要登录，公开官网不增加会员登录或注册。
- 工作台、产品、分类与品牌、媒体、文章、询盘和网站设置。现有通用内容接口与原型字段需对齐；专用产品参数、证书/首页管理按确认需求补充，不宣称已完成。
- 产品图片在产品管理中上传/替换并关联产品；分类与品牌只从产品记录汇总展示，不提供独立新增、编辑或删除。
- 媒体资源仅轮播图与合作商标，分组展示，固定位置仅修改/替换，不提供新增或删除，不包含产品图片。
- 草稿、发布、下架及对应缓存失效，语言启用前校验词条和内容。
- 询盘脱敏列表及NEW/PROCESSING/CLOSED状态更新；授权明文查看、跟进备注与完整审计放入二期。
- 图片/PDF/视频由Java上传至服务器磁盘，不接OSS或Redis，不做转码点播。

## 2. 资源接入

当前媒体模型保存object key、原始名、类型、大小和发布状态，内容通过image_id引用；版本、语言等扩展字段尚未实现。

部署前核实宝塔站点和磁盘目录，不套用未知服务器路径。配置`MEDIA_PRIVATE_ROOT`、`MEDIA_PUBLIC_ROOT`及`MEDIA_PUBLIC_URL_PREFIX`，必须为互不包含的独立绝对目录；不能放在`.output`、target、JAR部署目录或容器可写层。

文件大小、类型及文件头校验，公开媒体与草稿/导出隔离，私有文件不可通过公开链接访问。

上传默认私有，通过认证Java接口下载；确认发布后复制到公开目录，Nginx通过`/media/` alias映射公开目录，不映射私有目录。关闭目录列表和文件执行，启用nosniff。

文件使用随机名，限制类型、文件头、大小与路径；文件头检查不等于病毒扫描。媒体删除/撤销发布尚无接口，不在前端伪装可用。数据库事务和文件操作需补偿，备份同时覆盖数据库及媒体目录。

视频上传预先处理好的 MP4，真实文件到位后启用播放器；不调用转码、点播或传输加速服务。

## 3. 登录安全

Spring Security、BCrypt、Servlet Session、HttpOnly/Secure/SameSite Cookie、CSRF、本机限流及退出失效。生产只用单Java实例；重启会丢失会话和内存缓存，用户重新登录。

开发普通密码使用`ADMIN_PASSWORD`，仅dev环境启动时转换BCrypt；`ADMIN_PASSWORD_HASH`只接受哈希，生产不允许普通密码。.env被Git忽略，文档和日志不记录实际密码。

同机反向代理需核实受信代理IP解析，不能相信任意X-Forwarded-For；限流在一期本机实现，不要求Redis，但上线前必须验证访客不会共用全部额度。

后台按钮权限只用于体验，真正授权由 Java 检查。操作日志不包含完整客户隐私或密码。
