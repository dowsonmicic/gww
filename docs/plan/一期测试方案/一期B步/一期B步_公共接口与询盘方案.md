# 一期B步：公共接口、数据库与真实询盘

更新日期：2026-10-20。Java基础接口已实现，官网API联调、MySQL与真实询盘验收待完成。

## 1. 目标

保留已确认页面，增加 Java 后端和真实数据能力，暂不做管理后台登录或 OSS 上传。

## 2. 范围

- Java 17 + Spring Boot + MyBatis + MySQL，统一 DTO/VO、Result、Validator、异常和日志。
- 产品、品牌、分类、文章、网站信息及语言的公共只读接口。
- 官网统一数据访问切换到 API，已存在 URL 和组件不重写。
- 实现询盘表单、CSRF、本机限流、服务端校验及真实保存。当前未实现验证码或回电专用接口；上线前补齐防机器人措施，不依赖Redis。
- 邮件提醒按配置启用，未配置 SMTP 时仍保存数据，不宣称通知成功。
- Knife4j + OpenAPI，公开/共用接口放`docs/api/md/`及`docs/api/json/`，管理/认证接口放`docs/admin/md/`及`docs/admin/json/`，docs/JAVA_API_INDEX.md保留索引。
- MySQL为一期正式数据库，H2仅本地开发；同步维护SQL字段表，后续通过V2、V3追加迁移。

## 3. 空数据库处理

数据库结构通过迁移创建，但初始业务记录可为空，不强制灌入虚构公司数据。

空数据时产品/文章返回空列表，官网展示清晰空状态，不报错、不静默伪装为真实数据；本地演示模式显式标记且与 API 模式分离。

真实资料经确认后可由受控迁移或维护流程录入，尚不开放任何无鉴权公网写接口作为临时后台。

公共 API 只输出已发布对应语言内容，不泄露草稿及完整询盘信息。

## 4. 安全与资源

- 读取按公开范围，询盘写入需防机器人措施及限流，询盘读取/修改仅管理员可用。
- MySQL仅内部网络，凭证使用环境变量，备份和日志脱敏。Redis不属于一期依赖。
- 2GB 资源按旧测试方案重新预算，验证初始化峰值；只在能稳定运行时扩展服务。
- OSS 上传、后台和 AI 均不运行；媒体继续使用一期A步资源模型。

## 5. 验收

- [ ] 空数据库下官网正常，产品/文章空状态正确
- [ ] 有确认样本时列表、详情及双语 API 正确
- [ ] 询盘保存成功才提示成功，失败可重试且不误报
- [ ] 不开放客户线索读取或无鉴权内容修改接口
- [ ] 参数校验、防机器人措施、限流和异常格式通过测试
- [ ] API 文档、JUnit 5/接口测试及备份验证完成
- [ ] 2GB 单机联调和持续运行通过，未通过则先调优/确认升级

本步不包含管理员登录、后台内容编辑、OSS 上传及 AI。
