# 其他搜索引擎优化方案（Bing / 百度 / DuckDuckGo）

> Google 是主战场（见 `google搜索优化SEO.md`），本方案覆盖 Google 之外的搜索引擎优化要点。
> **结论先行**：Google 那套做好了，Bing / DuckDuckGo 基本自动吃到。百度需要额外几件事。

---

## 一、各搜索引擎共用 vs 独有信号

| 信号 | Google | Bing | DuckDuckGo | 百度 |
|------|--------|------|------------|------|
| robots.txt | ✅ | ✅ | ✅ | ✅ |
| sitemap.xml | ✅ | ✅ | ✅（通过 Bing） | ✅（但有自己的提交入口） |
| canonical URL | ✅ | ✅ | ✅ | ✅ |
| hreflang | ✅ | ✅ | ✅ | ✅（但百度不严格按 hreflang 排） |
| title / description | ✅ | ✅ | ✅ | ✅ |
| SSL（HTTPS） | ✅ 排名因子 | ✅ | ✅ | ✅ |
| 加载速度 | ✅ 排名因子 | ✅ | ✅ | ✅ |
| schema.org JSON-LD | ✅ Rich Results | ✅ | ✅ 部分支持 | ❌ 基本不认 |
| OG / Twitter Card | ✅ 社交分享 | ✅ | ✅ | ❌ 不认 |
| `<meta name="keywords">` | ❌ 2009 年已放弃 | ❌ 2016 年已放弃 | ❌ | ✅ **百度还在用** |
| 百度站长平台验证 | — | — | — | ✅ **必须** |
| 百度主动推送 API | — | — | — | ✅ **必须，影响收录速度** |
| 百度推送（js代码） | — | — | — | ✅ 可选，加速收录 |
| 备案号 | ❌ 不需要 | ❌ | ❌ | ✅ **国内域名必须** |
| `<meta name="render" content="webkit">` | ❌ | ❌ | ❌ | ✅ 告诉百度用什么内核渲染 |
| 百度结构化数据（BdSearchSchema） | — | — | — | ✅ 百度自己的一套 schema |

## 二、Bing / DuckDuckGo（几乎零额外工作）

### Bing Webmaster Tools

Bing 的 Webmaster Tools 和 Google Search Console 类似，**一个账号同时管 Bing 和 DuckDuckGo**（DuckDuckGo 大部分结果来自 Bing）。

| 步骤 | 说明 |
|------|------|
| **1. 注册** | [www.bing.com/webmasters](https://www.bing.com/webmasters) 用 Microsoft 账号登录 |
| **2. 域名验证** | 和 Google 一样，DNS 验证最快 |
| **3. 提交 sitemap** | 填 `https://yourdomain.com/sitemap.xml` |
| **4. URL Submissions** | Bing 提供批量提交入口，把产品 URL 批量贴进去 |
| **5. 等收录** | Bing 收录比 Google 快，通常 1-2 周 |

### Bing 特有的小技巧

| 技巧 | 说明 |
|------|------|
| **Bing 对 schema.org 的 Product 支持比 Google 还好** | 同一个 JSON-LD，Bing 也能出 rich result |
| **Bing 喜欢"干净"的页面** | 不要有弹窗、广告、过多 CSS class——你站本来就干净 ✅ |
| **Bing 对新站不设沙盒期** | 没有 Google 前 3-6 个月的"软沙盒"，新站 Bing 排名可能比 Google 先上来 |
| **DuckDuckGo 全看 Bing** | 做好 Bing，DuckDuckGo 自动有——不需要单独操作 |

### 给 Bing 加一点关键词权重

Google 忽略 `<meta name="keywords">`，但 **Bing 还在弱使用**。可以在每个页面加一行：

```ts
// useHead 里加
meta: [
  // ...
  { name: "keywords", content: "塑料原料, TPV, TPU, 聚丙烯, 聚乙烯, GWW" },
]
```

## 三、百度（需要额外 1-2 天工作）

百度和 Google/Bing 有本质差异——**它不完全遵循通用标准**。国内客户的询盘，百度可能和 Google 各占一半。

### 3.1 必须做的（不做百度几乎不收录）

| 步骤 | 说明 |
|------|------|
| **1. 备案号** | 如果域名在国内，必须有 ICP 备案。备案号放在页脚 `<meta>` 和页面底部。没有备案百度可能直接屏蔽 |
| **2. 百度资源平台（原站长平台）** | [ziyuan.baidu.com](https://ziyuan.baidu.com) 用百度账号登录，域名验证（HTML 文件验证最快） |
| **3. 百度主动推送 API** | 百度独有的——每次发布新内容，主动 POST 给百度，**比 sitemap 快 10-20 倍收录** |
| **4. 百度普通收录** | 提交 sitemap.xml 到百度资源平台的"数据引入 → sitemap" |

### 3.2 百度主动推送 API（最关键）

这是百度和 Google 最大的区别——Google 靠 sitemap 和爬取，百度靠**主动推送**。每次后台发布新产品，调用百度 API：

```
POST http://data.zz.baidu.com/urls?site=yourdomain.com&token=你的token

Content-Type: text/plain

https://yourdomain.com/zh/products/{id}
https://yourdomain.com/en/products/{id}
```

**token 在哪取**：百度资源平台 → 数据引入 → 普通收录 → 获取推送接口 token。

**怎么集成**：后端 `ContentService.save()` 发布 PUBLISHED 产品时，异步调百度推送 API。伪代码：

```java
// ContentService.java save() 方法末尾，产品发布成功后异步推送
if ("PUBLISHED".equals(dto.status())) {
    CompletableFuture.runAsync(() -> {
        String urls = "https://yourdomain.com/zh/products/" + row.getId() + "\n"
                    + "https://yourdomain.com/en/products/" + row.getId();
        // POST 到 data.zz.baidu.com
    });
}
```

> 也可以用 HTTP 响应头 `Link: <...>; rel="canonical"` 方式推送，但主动 API 更快。

### 3.3 百度推送 JS 代码（可选，最简单）

不想改后端？百度提供一段 JS，加在每个页面底部——**百度爬虫访问页面时，会自动把页面 URL 回传给百度**：

```html
<!-- 百度推送（放在所有百度能爬到的页面底部） -->
<script>
(function(){
    var bp = document.createElement('script');
    var curProtocol = window.location.protocol.split(':')[0];
    bp.src = curProtocol === 'https'
        ? 'https://zz.bdstatic.com/linksubmit/push.js'
        : 'http://push2.baidu.com/push.js';
    var s = document.getElementsByTagName("script")[0];
    s.parentNode.insertBefore(bp, s);
})();
</script>
```

但注意：**这段 JS 对 SSR 页面有用，对 SPA 页面没用**。你的站是 SSR，直接加就行。Nuxt 里在 `app.vue` 用 `useHead` 注入：

```ts
// app.vue
useHead({
  script: [{
    // 百度自动推送（可选，和主动 API 二选一或都加）
    innerHTML: `(function(){var bp=document.createElement('script');var p=window.location.protocol.split(':')[0];bp.src=p==='https'?'https://zz.bdstatic.com/linksubmit/push.js':'http://push2.baidu.com/push.js';var s=document.getElementsByTagName('script')[0];s.parentNode.insertBefore(bp,s);})();`,
  }],
});
```

### 3.4 百度特有的 meta 标签

```ts
// useHead 里加（只有百度认）
meta: [
  // 告诉百度用 webkit 内核渲染（默认移动端好）
  { name: "render", content: "webkit" },
  // 备案号（国内域名必须）
  { name: "icp", content: "粤ICP备XXXXXXXX号" },
  // keywords（百度唯一还认的）
  { name: "keywords", content: "塑料原料, TPV, TPU, 聚丙烯, 聚乙烯, GWW, 道达尔, 中石化" },
]
```

### 3.5 百度结构化数据（可选）

百度不认 schema.org，但有自己的一套 **BdSearchSchema**：

```ts
useHead({
  script: [{
    type: "application/ld+json",
    // 百度产品结构化（参考百度资源平台文档）
    children: JSON.stringify({
      "@context": "https://ziyuan.baidu.com/contexts/cambrian.jsonld",
      "@type": "Product",
      name: product.value?.model,
      brand: { "@type": "Brand", name: product.value?.brand },
      description: pageDescription.value,
      image: product.value?.image ? `https://yourdomain.com${product.value.image}` : "",
      url: `https://yourdomain.com${route.path}`,
    }),
  }],
});
```

> 注意：JSON-LD 的 `@context` 换成百度的 `cambrian.jsonld`。这套在百度资源平台 → 结构化数据里提交后，百度搜索结果可能出产品卡片。

### 3.6 百度不做什么

| 不要做 | 原因 |
|--------|------|
| 不要加百度统计（SEO 不加分） | 百度统计只能看数据，不影响排名 |
| 不要做百度竞价（和 organic 无关） | sem.baidu.com 是竞价广告，和自然排名两套系统 |
| 不要提交死链不处理 | 百度对 404 容忍度比 Google 低——产品下架要返回 404，不能留空壳页 |

## 五、修改建议

如果要同时优化三个引擎，在 `[[...slug]].vue` 的 `useHead` 里把 keywords 加上（无害，Google/Bing 都忽略但百度认）：

```ts
// 每个产品页动态生成 keywords
const pageKeywords = computed(() => {
  if (view.value?.type === "product") {
    const p = product.value;
    const items = ["塑料原料", "plastic materials"];
    if (p.brand) items.push(p.brand);
    if (p.model) items.push(p.model);
    if (p.category) items.push(p.category);
    items.push("GWW");
    // 中文页去掉英文关键词
    if (locale.value === "zh") {
      items.splice(items.indexOf("plastic materials"), 1);
    } else {
      items.push("supplier");
    }
    return items.join(", ");
  }
  return locale.value === "zh" ? "塑料原料, TPV, TPU, 聚丙烯, 聚乙烯, GWW"
                               : "plastic materials, TPV, TPU, polypropylene, GWW";
});

// useHead meta 里加
{ name: "keywords", content: pageKeywords.value },
```

百度资源平台注册、主动推送 API 集成和备案号填写，都是**部署后做的运营工作**，不影响代码。
