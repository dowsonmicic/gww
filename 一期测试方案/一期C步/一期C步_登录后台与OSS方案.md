# 一期C步：管理员登录、内容后台与 OSS

前提：一期B步完成并验收，本步另行批准实现。

## 1. 目标与范围

- Vue + Element Plus 后台，管理员登录、退出、密码修改、角色与服务端接口授权。
- 仅后台需要登录，公开官网不增加会员登录或注册。
- 分类、品牌、中英文产品/参数、文章、证书、首页及网站配置维护。
- 草稿、发布、下架及对应缓存失效，语言启用前校验词条和内容。
- 销售询盘列表、脱敏详情、授权明文查看、跟进与审计。
- 接入已有阿里云 OSS，管理图片/PDF/视频，不做转码点播。

## 2. 资源接入

统一媒体模型保存 object key、类型、语言、版本、权限和引用。一期A步静态资源可逐批迁移，迁移前后链接及引用一致，不要求一次性全量上传。

核实 Bucket 地域及存量内容；独立测试前缀/桶，受限 RAM 权限，凭证仅服务端。可按授权和文件类型采用短期签名/STS 直传，上传结果由服务端确认。

文件大小、类型及文件头校验，公开媒体与草稿/导出隔离，私有文件不可通过公开链接访问。

浏览器直传不代表放开 Bucket 公共写权限；CORS 白名单、签名过期和 key 范围受控。

视频上传预先处理好的 MP4，真实文件到位后启用播放器；不调用转码、点播或传输加速服务。

## 3. 登录安全

Spring Security、BCrypt、Redis 会话、HttpOnly/Secure Cookie、CSRF、登录限流及退出失效。

后台按钮权限只用于体验，真正授权由 Java 检查。操作日志不包含完整客户隐私或密码。

## 4. 验收

- [ ] 401/403、CSRF、登录退出和角色权限正确
- [ ] 草稿不可见、发布可见、下架与缓存同步
- [ ] 中英文内容独立编辑，共享产品身份
- [ ] OSS 上传、预览、引用检查及受控删除正确
- [ ] 非法文件、过期凭证和越权对象访问被拒绝
- [ ] 询盘查看、脱敏、跟进和审计正确
- [ ] 无 AI 功能或入口，无转码点播费用
- [ ] 2GB 容量复测通过；不通过先说明影响并确认调优/升级

交付新增接口 Markdown/JSON、后台源码、数据库迁移及 OSS 配置说明。
