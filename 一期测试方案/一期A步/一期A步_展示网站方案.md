# 一期A步：先交付可浏览的展示网站

状态：用户已授权实现，2026-10-17 本地实现及自动化验证完成，页面人工审阅及阿里云部署待完成。目标是先看得到完整官网效果，不以后台或数据库为前提。

## 1. 页面范围

| 页面 | 展示内容与交互 |
| --- | --- |
| 首页 | 导航、首屏、材料品牌/类别、推荐产品、企业介绍、优势、资讯及联系方式 |
| 关于我们 | 企业介绍及视觉展示；正式文案未提供时明确为待确认展示文案 |
| 产品列表 | 本地产品数据，分类/品牌筛选、关键词搜索、分页或有限列表 |
| 产品详情 | 示例型号、应用介绍、参数展示结构及联系入口，不编造真实技术参数 |
| 新闻/材料知识 | 本地示例文章列表和详情，未提供真实文章时标明示例 |
| 荣誉资质 | 预留页面结构，未提供证书时显示真实的“资料待补充”，不生成假证书 |
| 联系我们 | 已确认联系方式；未确认项不填写虚构号码，不提供假的留言提交 |
| 基础页面 | 404、手机导航及顶部语言切换 |

参考站作为布局和视觉方向，不复制其企业身份、图片、电话或授权声明。

一期A步按多页面官网设计，不仅是一张不可交互首页。复杂筛选算法、交易、会员均不做。

## 2. 明确不包含

登录、注册、权限、后台页面、Java 服务运行、数据库连接/建表/写入、OSS SDK/上传、真实留言保存、回电提交、AI、视频转码和点播。

联系方式页面不显示可提交却无后端保存的表单，也不弹出虚假的“已提交成功”。一期B步再启用真实询盘表单。

## 3. 技术与素材

- Vue 3 + Nuxt + TypeScript，官网自定义样式，版本实施时核实并锁定。
- 本地数据模块与统一内容访问边界，为 Java 公共 API 留替换点。
- 默认中文，中英文按钮切换对应页面；首次无明确选择时使用 `SITE_DEFAULT_LOCALE=zh`。
- 使用 Nuxt 服务端运行时配置读取默认语言，重启可改，无需重建；只列已启用且有词条的语言。
- 中英文示例内容及导航/错误提示一起维护，语言扩展不写死两套组件。
- 图片按用户最新指定，使用 `.images/lb`、`show`、`brands` 的提供素材，复制为项目静态资源，不接 OSS，不另行生成图片。
- PDF/视频未提供时不假造资源；第一步可只展示图文，不强制插入播放器。
- 不显示登录或 AI 入口，不创建隐藏 AI 组件。

## 4. 单一人工客服入口

默认一个“在线客服 / Contact Support”入口。若已提供受认可人工联系链接，则打开对应渠道并说明是外部联系。

未配置平台/账号时，点击跳转联系页，入口文案改为“联系我们”，不显示假聊天窗口、“客服在线”或假机器人回复。

真正的第三方人工聊天插件可在一期D步接入，一期A步不因此阻塞页面展示。

## 5. 阿里云测试部署

已有 2 核 2GB 服务器仅运行 Nginx 和单实例 Nuxt。初始可为 Nuxt 预留 384-512MiB 容器预算，实际以启动和样本压测结果调整。

本地构建后部署，先核实原有业务、端口、地域及剩余资源。大陆域名公开访问核实备案；未授权不改线上配置。

测试站仅供审阅，添加 noindex 并避免进入正式站点地图；noindex 不等于访问控制，不能放敏感资料。正式上线阶段再开放收录。
